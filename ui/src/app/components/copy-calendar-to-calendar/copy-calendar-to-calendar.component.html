Sync behaviour

Add missing workouts (default) Add missing selected workouts. Existing matches are left alone, even if their content changed; nothing is removed.
Mirror current TR simulation Add missing workouts of the selected types, update changed matches and remove eligible stale Intervals.icu workouts. Unchanged matches are left alone.

For matches, Mirror compares the name, type and generated description, including workout steps. It also compares the TrainerRoad start time, or the default if no TrainerRoad time is set. Otherwise it preserves the Intervals.icu time. Separately edited workout files and workout documents are not compared.

An Intervals.icu workout is stale when no TrainerRoad workout with the same ID and date exists in the selected range, regardless of workout type. Duplicate or ambiguous matches are skipped.

Mirror may overwrite or remove Intervals.icu workouts with a clear TrainerRoad ID in their description, including manual edits and workouts not created by this app. Stale workouts may be removed on empty days, for unselected types or when a corresponding TrainerRoad activity has no ID. Workouts without a recognizable ID are not removed, but a corresponding TrainerRoad workout may be copied again.
